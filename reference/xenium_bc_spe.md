# Description of the scider example datasets

scider-package has 1 datasets:

- xenium_bc_spe Example test spatial transcriptomics data in
  SpatialExperiment format. This test data is randomly subsetting from a
  publicly available 10X Xenium breast cancer data. Source data:
  https://www.10xgenomics.com/resources/datasets/xenium-ffpe-human-breast-with-custom-add-on-panel-1-standard

## Usage

``` r
data("xenium_bc_spe")
```

## Format

A SpatialExperiment object

## Value

A SpatialExperiment object

## Examples

``` r
data(xenium_bc_spe)
```
