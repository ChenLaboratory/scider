# Read VisiumHD output into spe

Read VisiumHD output into spe

## Usage

``` r
readVisiumHD(dir, bin = c("016um", "008um", "002um"), ...)
```

## Arguments

- dir:

  directory containing the VisiumHD files

- bin:

  Which bin size to use. Options of "016um","008um", and "002um"

- ...:

  Parameters for readVisium
